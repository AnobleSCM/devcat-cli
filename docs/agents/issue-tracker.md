# Issue Tracker

**GitHub Issues on `AnobleSCM/devcat-cli` is this repo's tracker.** File bugs,
scanner-support requests, and multi-session work here — not in `bd` (that's
in-repo working-state only) and not in the knowledge plane (that's for
durable findings/decisions, linked from issues when relevant, never copied).

No special label taxonomy yet — use plain, descriptive titles and let labels
emerge as the issue count grows. Triage/claim discipline follows the
workspace-wide protocol: `~/Developer/ecosystem-alignment/docs/agents/github-work-protocol.md`.
